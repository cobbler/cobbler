# Cobbler [3.3.8](https://github.com/cobbler/cobbler/tree/v3.3.8) - 2026-08-28


## Fixed

- support for import and manage of openSUSE Leap 16 and new Agama installer
  [#3419](https://github.com/cobbler/cobbler/issues/3419)
- XML-RPC generate_autoinstall now normalizes empty string parameters to None,
  preventing incorrect error banner when clients send "" instead of null
  [#3807](https://github.com/cobbler/cobbler/issues/3807)
- Basic support for Python 3.13
  [#3826](https://github.com/cobbler/cobbler/issues/3826)
- Fix url for wimboot when importing Windows distro
  [#3887](https://github.com/cobbler/cobbler/issues/3887)
- check: Use systemctl is-active --quiet to check the status of services
  [#3942](https://github.com/cobbler/cobbler/issues/3942)
- Added support for interactive and automatic network installations of XCP-ng
  7.x and 8.x latest releases.
  [#3980](https://github.com/cobbler/cobbler/issues/3980)
- SHA-pin GH Actions inside the CI
  [#4067](https://github.com/cobbler/cobbler/issues/4067)
- Aligned CNAME records in generated BIND zone files into columns, matching the
  existing A/AAAA/PTR record formatting.
  [#4070](https://github.com/cobbler/cobbler/issues/4070)
- Fix crash while writing the bind reverse zone when a host's IPv6 address
  contains a non-numeric hex character
  [#4072](https://github.com/cobbler/cobbler/issues/4072)
- Fix UnicodeDecodeError in `cobbler status` when reading rotated/compressed
  install logs [#4084](https://github.com/cobbler/cobbler/issues/4084)
- Fix genders module failing to load on Python 3.12+ due to removed distutils
  module [#4086](https://github.com/cobbler/cobbler/issues/4086)
- Add missing root=live: kernel parameter for Agama PXE installs so the
  installer can find its live media over the network
  [#4088](https://github.com/cobbler/cobbler/issues/4088)
