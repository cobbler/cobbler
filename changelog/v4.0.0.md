# Cobbler [4.0.0](https://github.com/cobbler/cobbler/tree/v4.0.0) - 2026-11-27


## Security

- Remove `shell=True` from subprocess calls to avoid shell injection risk.
  [#2859](https://github.com/cobbler/cobbler/issues/2859)
- Fixes a permission regression in the mod_wsgi script from a prior CVE fix.
  [#2967](https://github.com/cobbler/cobbler/issues/2967)
- Lowers filesystem permissions on `modules.conf` for the SVC script.
  [#4164](https://github.com/cobbler/cobbler/issues/4164)
- Fix insecure protocol usage in network operations.
  [#4168](https://github.com/cobbler/cobbler/issues/4168)
- Requires Python 3.11+, bumps libcobblersignatures to 0.5.1, blocks modifying
  item ctime/depth via `modify_item`, and closes an XML-RPC transaction
  authorization-bypass/timeout gap.
  [#4199](https://github.com/cobbler/cobbler/issues/4199)


## Removed

- Makes `modules.conf` obsolete/no longer required.
  [#3032](https://github.com/cobbler/cobbler/issues/3032)
- Makes `mongodb.conf` obsolete/no longer required.
  [#3033](https://github.com/cobbler/cobbler/issues/3033)
- Removed file, mgmtclass and package item types
  Removed puppet HTTP endpoint
  [#3536](https://github.com/cobbler/cobbler/issues/3536)
- Remove built-in CLI [#3934](https://github.com/cobbler/cobbler/issues/3934)

## Fixed

- Security: Fix issue that allowed anyone to connect to the API as admin
  [#cve-2024-47533](https://github.com/cobbler/cobbler/issues/cve-2024-47533)

  startup. [#532](https://github.com/cobbler/cobbler/issues/532)
- Give per-system, per-profile, and per-distro Cheetah snippets the same
  ListErrors handling as general snippets, so variables resolve consistently
  and a missing variable stays inside the snippet.
  [#1186](https://github.com/cobbler/cobbler/issues/1186)
- Fix the ownership authorization module raising an authorization error for
  every non-admin save/modify, including creating new objects, instead of
  correctly checking ownership against the object itself. Removing, copying,
  and modifying templates, menus, network interfaces, and the group item types
  also no longer crash with the same error, and copying an object now correctly
  requires ownership instead of always being denied for non-admins. A new
  object whose owners were never explicitly set is now auto-assigned to the
  creating user's own group (or, if they belong to several groups, the save is
  refused with an explanation instead of guessing), so non-admin users can
  create new objects without being immediately locked out of them.
  Power-cycling a system now also requires ownership. Also close a
  name-collision gap where a new object could be used to bypass the real owner
  of an already-existing, differently-owned object of the same name.
  [#1522](https://github.com/cobbler/cobbler/issues/1522)
