# Cobbler [4.0.1](https://github.com/cobbler/cobbler/tree/v4.0.1) - 2026-11-27


## Notice

- **Cobbler 4.0.1 is identical to Cobbler 4.0.0.** After a publishing mistake
  the `4.0.0` tag is not available on PyPI, so the exact same code was
  re-released under the version `4.0.1`. Apart from the version number
  (including a schema-identical `V4.0.1` settings migration step so that the
  installed version can be resolved), no functional changes were made. Please
  refer to the [4.0.0 changelog](v4.0.0.md) for the complete list of changes.
